This website is built using [11ty](https://11ty.dev) based on the [Eleventy Excellent](https://eleventy-excellent.netlify.app/) starter project. 
The [code](https://github.com/trashnotslop/trashnotslop.com) is hosted on [GitHub](https://github.com) and the website is hosted on [Netlify](https://netlify.com), with [Hover](https://hover.com) as the domain registrar. 
Development is mostly done in the [Zed editor](https://zed.dev) with [Ghostty](https://ghostty.org/) as the terminal, and viewed in the [Zen browser](https://zen-browser.app/).
